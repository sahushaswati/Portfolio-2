# Shaswati Sahu — Interactive Portfolio

A responsive, dark-modern personal portfolio built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout, theme and animations
- `script.js` — menu, typing effect, theme switch, scroll effects and project dialog
- `assets/` — add your resume PDF and optional images here

## 1. Preview locally
1. Extract this ZIP.
2. Open the `shaswati-portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## 2. Personalize before publishing
Search the files for `YOUR-` and `[Add` and replace the placeholders:
- `YOUR-GITHUB-USERNAME` — your GitHub username
- `YOUR-EMAIL@example.com` — your professional email (replace in both `index.html` and `script.js`)
- Add your resume as `assets/resume.pdf`
- Add your senior-secondary and school names, boards, years, graduation year and CGPA
- Verify the college name and all project details
- Add project screenshots or links only if they are real and publicly accessible

The portfolio currently uses a text/code illustration, so no profile photo is required.

## 3. Create your GitHub repository
1. Sign in at https://github.com/
2. Click **New repository**.
3. For a personal site, name it exactly `YOUR-GITHUB-USERNAME.github.io`.
4. Set it to **Public** and create it.
5. Upload the contents of this folder (not the outer ZIP) to the repository root. Make sure `index.html`, `style.css` and `script.js` are at the root.

## 4. Publish with GitHub Pages
1. Open the repository's **Settings**.
2. Choose **Pages** from the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`.
5. Click **Save**.
6. Wait for the Pages deployment to finish. Your site should be at `https://YOUR-GITHUB-USERNAME.github.io/`.

## 5. Test the live website
- Open it on a phone and a computer.
- Test the menu, theme switch, project details popup and navigation.
- Check that the email and LinkedIn links work.
- Check that the resume downloads.
- Check for any remaining placeholders.

## Important accuracy notes
- The project text is based on the details supplied so far. Update it to match the exact features you personally implemented.
- Do not list a live demo or source-code project URL until you have deployed/published it.
- Keep only skills you can explain in an interview.
- GitHub Pages serves static files. A Java backend needs separate hosting if you want a live backend demo.
